How the pipeline is scoped

LOCAL TIMELINE.
SELECTIVE CLOUD AI.

SMITH CUT
✓ Works from the active Premiere sequence by default
✓ Rough-cut planning and Premiere placement run locally
✓ Full raw media files are not uploaded for rough-cut builds
✓ AI Story uses still-frame samples and metadata, not full video files
✓ Subtitle and interview tools transcribe extracted dialogue chunks only when requested
✓ Duplicate-sequence workflow protects the editor's original timeline
GENERIC AI EDITORS
✗ Often built outside the Premiere timeline first
✗ May require uploading full media for analysis
✗ May hide which timeline edits will be applied until export
✗ Can force an upload/download workflow before Premiere refinement
✗ General-purpose outputs can be harder to audit in a pro timeline
✗ Less focused on editor-controlled review before applying changes

Smith Cut uses cloud AI only for workflows that need transcription, caption formatting, or visual reasoning. Beat-sync timeline planning does not upload full source media.

The pipeline

PICK A TASK.
REVIEW THE RESULT.

01
Open a Sequence
Smith Cut reads the active Premiere sequence, including video clips, audio tracks, basic timing, and available media paths.
02
Choose a Workflow
Sync to Beat, Cut Up an Interview, or AI Subtitles. The panel only shows the source, rhythm, transcript, and caption controls needed for that task.
03
Analyze
Beat-sync uses local audio analysis. Subtitles and Creator Mode can transcribe dialogue chunks through Smith Cut Cloud and then return timestamped segments.
04
Apply Safely
Rough cuts and beat alignment default to a duplicate sequence. Interview cuts are reviewed before apply. Captions can be exported as SRT or placed as styled MOGRT graphics.
