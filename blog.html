What Smith Cut Does Today

Smith Cut is now a Premiere-native CEP panel. The current product does not treat the editor like they are starting in a separate media-ingest app. It reads the active Premiere sequence and uses that timeline as the default source of truth.

The main workflows are Sync to Beat, Cut Up an Interview, and Add AI Subtitles. Each workflow reveals only the controls it needs, so a captions job does not have to look like a beat-sync job.

Current default: open a sequence, open Smith Cut, choose a workflow, review the result, and apply it intentionally.

Beat-sync rough cuts and timeline placement run locally on the Mac. AI Story sends still-frame samples and metadata. AI subtitles and Creator Mode can send extracted dialogue audio chunks for transcription when the user runs those workflows.

Beat-Sync Without Wrecking Timelines

Build Rough Cut creates a beat-aware first pass from current Premiere media. The current host tools are designed to work on a duplicate sequence by default so the original sequence remains intact for comparison.

Align to Beat is different. It is meant for an existing sequence where the editor already has cuts and wants those cuts moved toward detected musical beats when the operation is safe.

Smith Cut should never surprise an editor by turning a readable timeline into dozens of tiny fragments. The app has minimum watchable cut-length protection, and when alignment cannot be applied safely, the right behavior is a warning rather than destructive busywork.

AI Subtitles and Social Captions

The subtitle workflow transcribes dialogue from the active sequence, formats readable caption blocks, and saves an SRT file. Editors can import the SRT into Premiere for editable captions.

For social video, Smith Cut can also place styled caption graphics on the timeline with a MOGRT template. The MOGRT controls the visual design; Smith Cut supplies text, timing, and optional highlight fields when the template exposes compatible parameters.

Template rule: user-provided MOGRTs are viable when their exposed controls match the expected caption text and optional highlight fields.

Timing is the core quality bar. Smith Cut preserves speech gaps and uses detected speech regions so captions do not get stretched evenly across silence.

Cut Up an Interview with Review First

Creator Mode builds or receives timestamped dialogue segments, then asks the AI to classify what should be kept, tightened, or removed. The UI supports Light, Standard, and Aggressive cleanup modes plus Fast, Standard, and Pro analysis tiers.

Instead of applying cuts instantly, Smith Cut shows transcript review and marker preview first. The editor can inspect the suggestions before applying approved cuts.

That review step is not a luxury. Interview cleanup is subjective, and silent deletion can break meaning. Smith Cut should act like an assistant, not a final editor.

Installing the CEP Panel

Smith Cut is delivered as a folder or beta package with setup scripts, Python tools, CEP panel files, and assets. Run the setup script, install the CEP extension if your package separates that step, then restart Premiere Pro.

In Premiere, open Window -> Extensions (Legacy) -> Smith Cut. The Smith Cut panel is the bridge to Premiere. The old Pymiere Link workflow is no longer part of the current product path.

Paste your Smith Cut license key in Settings. License validation and AI credits are server-side, so activation, AI workflows, and credit top-ups require internet access.
